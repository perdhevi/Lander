Stage 1

A single neuron

A neuron is just three things: a list of weights, one bias number, and an activation function.

  • Multiply each input by its weight.
  • Add them up, then add the bias.
  • Pass the sum through the activation.

Line thickness shows how big a weight is. Blue means positive, orange means negative.

Try this: set the activation to ReLU and drag the bias down. Once the sum goes below zero, the neuron goes silent and outputs 0. That is the neuron deciding not to "fire".

Stage 2

A layer is a matrix

In real code there is no Neuron class. A layer of 3 neurons that each read 2 inputs is stored as a 3×2 matrix. Each row is one neuron's weights.

Running the whole layer is one line: y = relu(W @ x + b). It does the same work as a loop over every neuron, but a GPU runs all the rows in parallel.

Press Next row to step through the matrix multiply one neuron at a time.

Loop version
for i in range(3): s = b[i] for j in range(2): s += W[i][j] * x[j] y[i] = relu(s)
Matrix version
y = relu(W @ x + b) # same result, # one GPU call
Stage 3

A feed-forward network

Stack layers so each one's output feeds the next. Data flows one direction, left to right, with no loops. That is all "feed-forward" means.

This is the exact shape of the MLP inside every transformer block: expand (4 → 8), apply the activation, then shrink back (8 → 4).

Node color shows the value: blue positive, orange negative, empty means zero.

Turn the activation off and check the box underneath. Without it, the two layers give exactly the same answer as one combined matrix W2 @ W1. The depth was wasted. Turn ReLU back on and the shortcut no longer matches.

Stage 4

Attention: tokens reading each other

A feed-forward net handles each token alone. Attention is the step where a token pulls in information from other tokens.

  • Scores = Q·Kᵀ: how well the query "it" matches each key.
  • Softmax turns scores into weights that are positive and sum to 1.
  • Output = weighted mix of the value vectors.

The struck-out tokens are in the future. A decoder's causal mask hides them, so "it" can only look backwards.

Try this: turn softmax off and raise several scores. The output values grow past 1 and stop meaning anything. Then turn it back on and push the divisor up. The weights flatten out, which is what √d_k scaling does to huge scores.

Stage 5

The whole transformer

Now put the pieces together. Click through each stage to see what the data looks like at that point.

The middle part, attention then MLP, is one block. Real models repeat it 30 to 100 times. Each block reads the running vector for every token and adds its update back on top, the residual stream.

Stage 6

Picking the next token

The last vector is scored against the whole vocabulary. These scores are called logits. Softmax turns them into probabilities, and one token is sampled.

It is the same softmax as in attention, used for a different job.

Temperature divides the logits before softmax, just like √d_k. Low temperature makes the top choice dominate. High temperature makes unlikely tokens show up more often.
